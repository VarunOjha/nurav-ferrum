## Review issues: confirmed on HEAD 0989278 by reading the code, then fixed

1. Bar hides the end of pages and popups at 390 px: confirmed (.ui-ref-bar position:fixed, nothing reserved room).
   Fix: RefMode measures the bar (ResizeObserver) into --ref-bar-h; Ref mode adds that much + 24 px at the end of the
   page and of the big popups (and of the small reference popup on phones); the bar is one short line on phones; the
   bar no longer moves into the Layout map.
2. and 7. Header becomes two rows in Ref mode at 1440 / Ref button moves away: confirmed (globals.css row-gap 30px,
   padding-bottom 26px, column-gap 48px under html[data-ref-mode]). Fix: overrides removed; header labels show only the
   id (full name in tooltip and accessible name), 10 px, under each piece.
3. and 10. Log labels only on the newest entry: confirmed (app/log/page.tsx firstId / firstTablesId). Fix: every entry
   is marked; RefMode labels the first visible one per id and marks the rest data-ui-dup (no outline, no label);
   re-scanned when data-filter changes.
4. Item labels without a name: confirmed (OV-3, AR-3 ui() calls had no item). Fix: registry items with a fixed word.
5. Layout map has no jump links and always opens at the top: confirmed. Fix: jump links row; opens scrolled to the
   current tab's or open popup's group, highlighted ("this tab" / "the open popup"); indexed items listed under groups.
6. "Copied" follows the bar into a new popup: confirmed (status cleared only by its 8 s timer). Fix: cleared whenever
   the bar moves to another host.
8. Every tab shifts down 117-228 px: confirmed (margin-top 16px on every block, padding/gap overrides). Fix: removed;
   labels take no space (above in the gap, inside card padding, on popup header bottom borders, right-aligned in the
   small popups).
9. RM-2.N and AR-3.N numbered by list position: confirmed (index: i + 1). Fix: ui(id, { key }) looks up the item's own
   data id (stage id, first layer id of the row) in the registry's items table; unit tests check every stage and layer
   row in plan/portal is registered and that no ui() call uses a map index.
11. Focus lost after closing the Layout map / Turn off inside a popup: confirmed (bar host moved into the map; turn(false)
   focused the inert Ref button). Fix: bar not moved into the map and the opener refocused on close; Turn off inside a
   popup focuses the popup's first remaining button.
None rejected.
